# Deck template

Copy this directory to start a deck, then fill in the placeholders.

```bash
cp -r ~/.claude/skills/didactic-decks/assets/deck-template <project>/<module>/slides
```

It needs didactic v2.18 or later: the stamps in `preamble.tex` have that
version's form (`% sync english=… swedish=…`), and a bilingual deck's
blocks are `\begin{onlyin}{english}` (`references/bilingual.md`). Since
v2.17.1 didactic sets beamer's translator up for babel's Swedish, which
the Swedish block titles rely on (the template no longer does it
itself), and since v2.17.2 the English edition's `capitalise` also
reaches didactic's own reference names ("Exercise 1"). Use v2.18.1 or
later: it writes the transcripts (`didactic_output_*.txt`) into each
job's output directory, so the two editions no longer share them.

## Two layouts

The template ships **bilingual**: one source, two editions.

| Driver | Edition | Output directory |
|---|---|---|
| `notes.tex`, `slides.tex` | the course's main language (shipped as English) | `ltxobj` |
| `notes-sv.tex`, `slides-sv.tex` | Swedish | `ltxobj-sv` |

Each driver is four lines: it passes the edition's language to babel and
cleveref and inputs the shared document, `notes-body.tex` or
`slides-body.tex`. `references/bilingual.md` in this skill has the rules
for writing the two languages in one source.

- **English only**: delete `notes-sv.tex` and `slides-sv.tex`.
- **Swedish only**: delete them too, and in `notes.tex` and `slides.tex`
  set `main=swedish` and `english,swedish` (no `capitalise`), as the
  `PROJECT:` comment in `slides.tex` says.

The `Makefile` builds the `-sv` PDFs only when their drivers exist, and the
preamble's `\ensv` reference names pick the edition's half, so a
single-language deck needs no other change.

## Placeholders to replace

| Placeholder | Where | Replace with |
|---|---|---|
| `TITLE` | `slides-body.tex`, `notes-body.tex` (twice) | the deck title, identical in both; `\ensv{English}{Svenska}` in a bilingual deck |
| `AUTHOR` | `slides-body.tex`, `notes-body.tex` | the author |
| `INSTITUTE` | `slides-body.tex`, `notes-body.tex` | the institute, also as `\ensv` in a bilingual deck |
| `Module` in `ModuleLOFirst` | `abstract.tex`, `contents.nw` | the module's name, so labels read `<Module>LO<Aspect>`; `contents.nw` cross-references the same label from its `\ltnote` |
| `../../../makefiles` | `Makefile` | the relative path to the shared makefiles submodule |
| `examples/example.py` | `Makefile` | one `EXAMPLES+=` line per tangled program |

Lines marked `% PROJECT:` are language- or project-specific: the edition
lines in the drivers, the babel languages, the acro pattern, the
`\deftranslation` house terms in `slides-body.tex`, the appendix
headings, and the
`\chapterprecis` sentence.

The `\crefname` lines in `preamble.tex` carry `% sync` stamps written by
`didactic-sync.py`, so a new bilingual deck starts with its two languages
in step. Change those names only together with a new stamp
(`references/bilingual.md`, "Stamps").

## Placeholder files

The template builds and passes `build_deck.sh` as it is, so it carries
four placeholders to replace:

- `ltnotes.bib` — empty but for a comment; every entry needs a provenance
  block (load the `backing-claims` skill).
- `figs/example.png` — the figure `contents.nw` includes; replace it or
  delete that float.
- the footnote in `contents.nw` ("A pointer to an appendix or to another
  deck goes in a footnote …") — the numbered margin note the margin check
  needs; a real deck's own footnotes and `\autocite`s replace it.
- `litteratursokning/claim-full.tex` — stands where the search tool's hit
  list goes, `\input` from `sokprotokoll.tex`; the tool writes the real
  file under the claim's name.

`examples/` is entirely generated by the tangle rules and never committed.

## First build

```bash
make notes.pdf LATEXFLAGS="-shell-escape -interaction=nonstopmode"
make slides.pdf LATEXFLAGS="-shell-escape -interaction=nonstopmode"
make notes-sv.pdf LATEXFLAGS="-shell-escape -interaction=nonstopmode"
make slides-sv.pdf LATEXFLAGS="-shell-escape -interaction=nonstopmode"
```

One job at a time: the two jobs of an edition share an output directory.
`scripts/build_deck.sh` in this skill does the whole sequence, including
the convergence loop, the checks, and on a bilingual deck the sync check.
